# I.N.U.U-Release
INUU is an all-in-one Windows utility suite designed to clean, optimize, and manage your PC with ease. Features include junk cleaner, registry cleaner, app uninstaller, browser cleaner, monitor controls, and update center — all in a fast, lightweight, and modern interface.

Release Notes — I.N.U.U v8.06 (2026-05-10)

Version update to v8.06 across runtime constants and app storage namespace (INUU v.8.06). Dashboard network area improved: added dedicated Usage card next to Network Throughput with cumulative download/upload/total usage in compact MB/GB format. Password Directory import/export expanded: New import modes: CSV/Excel, INUU locked CSV, and TXT. Added CSV Template download button for import-ready column format. Improved import normalization and compatibility with common header variants. Update Center driver reliability improved: Windows Driver Catalog entries are now actionable (install command attached per update ID). Better install flow for driver updates via PowerShell/Windows Update. GPU update pipeline overhauled: Detection now supports multi-GPU and multi-vendor systems (NVIDIA, AMD, Intel). Added nvidia-smi fallback when needed. Replaced fragile hardcoded NVIDIA install path with vendor-aware Windows Update install commands. Fixed vendor classification edge case (Intel no longer misclassified as AMD). Stability/quality: Addressed UI clipping in Dashboard network metrics. Validated updated code paths with no syntax errors.
